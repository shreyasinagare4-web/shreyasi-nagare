# My Resume Website

This is my personal resume website, made for my Web Development module project. I built it using HTML and CSS.

## Live Website

file:///C:/Users/HP/Downloads/index3.html#about

## What's Inside

- `index.html` - the content of the website (about, education, skills, contact)
- `style.css` - the design of the website (colors, fonts, layout)
- `profile.jpeg` - my photo

## What I Used

- HTML for the structure
- CSS for styling
- Google Fonts (Poppins and Playfair Display)
- Flexbox for the navigation bar and cards

## Features

- Navigation bar with links to each section
- Cards for education and skills
- Hover effects on links and cards
- Color palette of green, dark blue-grey and orange

## What I Learned

I learned how to use fonts, colors and selectors to style a page, and how to host a website on GitHub.
